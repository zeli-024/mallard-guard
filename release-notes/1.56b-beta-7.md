# Mallard Guard 1.56b-beta-7

Requires Ducky Lib 0.1.0-beta-22 on clients and servers. Removes the retired duckylibdevtools Gradle subproject/build dependency and updates the library version check and runtime dependency. The source build produces the two required runtime jars.

All Mallard Guard Java sources and assets are identical to the previously tested 1.56b-beta-6 integration. Combat, configuration, defaults, permissions, networking, migrations and specialized previews are unchanged. Stable release 1.56a remains the pre-extraction baseline; this package does not relabel it.

Static source/build-wiring checks only. Compilation and in-game testing are performed locally by the user.
