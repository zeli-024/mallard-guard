# 1.55b-beta-5

- Perfect Only updates the unsaved screen immediately, revealing or hiding regular controls without Apply. Hidden values are preserved. Client Highlight timing uses client permissions/save ownership; server enforcement remains separate.
- Hitlag Off no longer cancels other enabled screen effects. Before-mode Highlight uses its duration without a freeze; with hitlag it ends exactly when the freeze ends. Impact Frame without hitlag filters the live world using the configured Hitlag Duration, falling back to that duration for zero regular timing. It does not freeze the world.

All player particle colors default white; all mob parry colors default red, including Flying Sparks, Debris, Tracers and the inherited Center Impact. All three spark families default to 8% Base, 32% Perfect and 2% Damage Intensity.

- Impact Frame and Highlight editing/preview screens pause single-player. Their playback uses a render clock; multiplayer servers remain live. Preview capture work restores render state.

Damage Sources now uses shared browser geometry, aligned headers/rows/footer, standard controls and a concise help dialog.

Added effect/capture timing, prediction replies/timeouts, particle budgets and assignment request counts. Collision profiling remains explicitly opt-in.
- Config revision 97 records new defaults; preset revision 91 retains stable slot positions. Saved custom values are preserved when keeping settings. Packet layout/protocol 72, dependencies, artwork, gameplay and animation playback are unchanged.

Validation: all 99 Java files pass lexical/grammar/import/declaration checks; packet constructor and codec consistency checks pass; interpreted Java decisions cover draft toggle callbacks, effect timing and independent effects; shared layouts checked at 35 GUI sizes.
