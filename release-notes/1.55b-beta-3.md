# 1.55b-beta-3

- Redesigned Punchy's pose editor with visible Guarding/Parried stages, Pose/Timing/Items workspaces, pinned part selection and a stable preview area. Manual UI opacity persists while editing. Timing curve choices and labels match batch editing.
- Replaced each preset's dots menu with square On/Off, pencil rename and confirmed Delete actions beside its name. Deleted built-in presets retain disabled storage slots for compatibility and disappear from selection/copy lists.
- Simplified Screen Effects to Hitlag, Impact Frame, Target Highlight, White Flash, Camera Shake and Chromatic Aberration. Perfect Only hides regular controls without erasing values. Feedback settings are shared when parrying and when parried. Removed the vignette asset/renderer and incoming-only FOV/effect controls.
- Impact Frame now occurs within hitlag, without a second hold. Target Highlight supports With/After Hitlag, role colors, independent lifetime and both fades; its target is excluded from world dimming. Alpha-tested weapon materials retain silhouette transparency. White Flash waits only for fullscreen feedback; Chromatic Aberration runs alongside it.
- Retained fixed white-flash fades; moved configurable screen durations to ticks with historical file/preset migration. Target Highlight defaults: Perfect Only, After Hitlag, 8 ticks, 30% world dim, 2-tick fade-in/out, 60% glow. Impact Frame defaults Off.
- Merged server health controls, grouped parry types and knockback, renamed Eligibility/Shield Options, moved shield attacker knockback, and set follow-up parries to 5 ticks. Added shared retaliation enable, perfect-only projectiles/falls and perfect knockback scaling. Falls always require downward aim.
- Parried gameplay has an enable switch, Stun/Guard Break selection and independent 10-tick durations capped at 60. Attack interruption is automatic while enabled. Existing guarding attack suppression is retained.
- Removed regular/perfect tracer color differentiation. Player tracer and impact colors use one cached palette; mob palettes remain server-owned.
- Updated migration, search grouping, enforcement, undo/reset/save paths, cleanup and documentation. Network protocol 72 requires matching versions on client and server.

Validation: lexical/grammar/declaration/signature checks across 99 Java files; changed codec field order/types and constructor arities; interpreted gameplay/timing decisions with mocked state; shared layout geometry at 35 sizes; archive/overlay integrity. No Java build or game execution was performed. Run the supplied Gradle command and test rendering, Punchy transitions and multiplayer locally.
