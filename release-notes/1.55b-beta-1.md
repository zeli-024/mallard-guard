# 1.55b-beta-1

- Fixed startup migration of older client configs so it reads only the loaded client settings, without accessing the separate Punchy config before it loads.
- Corrected the shield-block feedback packet to use LivingShieldBlockEvent.getDamageSource(), matching the event's existing damage handling.
- Corrected three dialog strings whose literal line breaks caused compilation errors. Java string/character literals are now checked separately from grammar parsing.
- Reworked the Punchy editor around Guarding Pose, Parried Pose, position, collapsible timing and item assignments. Enabled/Disabled buttons use readable text.
- Unified preset, supporting-hand and weapon allow/block assignments. Added exclusive preset ownership, shared assignment choices and confirmation before replacing another preset's ownership.
- Added native item tooltips and tooltip-text searching to assignment browsers. Large searches, bulk edits and ownership reviews use bounded client-thread work. Select Results and Clear Results cover offscreen matches without an item-count cap.
- Exact item rules use hash lookups. Active policies retain compiled rules; group and tag membership remain live. Tooltip caches have explicit memory budgets. Large configuration transfers retain compressed and decoded size bounds.
- Split regular/perfect tracer colors into separate three-color palettes. Matching center impacts inherit the outcome palette; shared player palettes and server-owned mob colors retain their ownership rules.
- Reorganized world-particle, screen-effect, HUD-icon and server settings. Added missing effect/component switches that preserve configured strength, separate flash durations and clearer labels.
- Added participant-only perfect-parry world dimming and opponent highlighting, with fade-in, brightness and glow controls. Spectators retain ordinary world effects and receive no screen highlight.
- Parried poses begin after hitlag and are cancelled by newer animation ownership. Existing prevention of attacks while guarding remains.
- Added configurable attack interruption and regular/perfect incoming stun, with independent client hitlag. Server stun owns gameplay restrictions; the existing stun system supplies one client timer and clears it on death/disconnect.
- Removed obsolete feedback UI branches and unused imports; updated assignment undo/reset and enforced-category handling.

Config revision 94; particle preset revision 89; payload protocol 70. Client and server must use the same version. Existing settings and palettes are migrated; new perfect colors initially inherit saved regular colors.

Source checks passed: Java grammar/local signatures, packet codec symmetry, shared geometry at 35 GUI sizes, matching with 10k/50k/100k mocked IDs, exception/tag cases, transfer budget checks and feedback/lifecycle invariants. No Java build or Minecraft runtime test was performed for this patch. Build and test locally before distributing it.
