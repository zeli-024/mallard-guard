# 1.55b-beta-2

- Added Off, Stun and Guard Break choices for incoming parries. Regular/perfect durations remain separate. Guard Break uses the existing recharge meter, without movement or attack stun.
- Added separate incoming FOV, shake, vignette, flash and Chromatic Aberration switches, strengths and durations. FOV Change defaults off; our stun movement modifier no longer changes FOV accidentally.
- Perfect-parry dimming and highlighting now have their own duration and respect the configured fade-in time. The effect ends immediately without fading out. The opponent's visible mask is excluded from world dimming; silhouette brightness and glow remain adjustable.
- Added an in-game Highlight Preview with replay, nearby-target selection, editable controls and explicit Apply/Discard. It uses the same mask/shader without sending a combat event.
- Highlight Preview now holds a steady full-strength effect while editing. Play Once separately tests fade-in and lifetime; sliders no longer restart the animation or recreate the mask buffers.
- Compositing puts dimming/highlight below the impact screen filter. The highlight glow is confined to a narrow inner edge, without an outward halo.
- Highlight masks retain the original material texture and shader alpha, including weapon sprites, instead of filling transparent PNG padding. Material batches are reused and unused batches are released.
- Parry flash waits for the other screen effects to finish, or plays immediately if none are active. Chromatic Aberration starts alongside feedback and is excluded from that wait. Include HUD controls whether its final pass processes the HUD too. World particle lifetimes remain independent.
- Restored the Chromatic Aberration name. Closed dividers remain closed instead of reopening Hitlag. Added player impact inversion to the existing impact-frame preview/editor.
- Retained the beta-1 compile and startup migration corrections. Removed obsolete effect-order code and kept shared save/reset/enforcement handling for appended settings.

Config revision 95; particle preset revision 89; payload protocol 71. Client and server need matching versions. Earlier preset lengths are accepted and new controls receive defaults.

Source checks cover Java literals and grammar, project signatures, payload layouts, reaction decisions, highlight lifetime/compositing, shared UI geometry and cleanup overlay. No Java build or game runtime was run here.
