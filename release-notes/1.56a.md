# 1.56a

## Changes since 1.54e

- **Punchy Parried Poses**
- **Target Highlighting**
- **Icon Location Change**, including size adjustment
- Fixed Punchy animation priority handling during perfect parries.
- Fixed older Punchy animations interfering with newer animation ownership.
- Improved config change detection and reduced redundant config save/sync work.
- Corrected compatibility imports and optional-mod fallback handling for Simply Swords, Shield Expansion, Punchy and Better Combat.
- Fixed disabled features continuing their rendering or dependent work.

## Details

- Default hitlag is 3 ticks for perfect parries and 1 tick for regular parries; Perfect Only stays Off. Impact Frame looks best with 6 perfect hitlag ticks; enabling it does not change timing automatically.
- Added whole-preset Undo to the Punchy editor header. It restores both poses, timing and every assignment from the last saved preset; new presets return to their initial draft. Nothing is written until Save.
- The shield icon now defaults to Bottom Center, with a 50–200% size slider (default 100%) alongside Gap.
- Icon placement fades its controls while dragging and supports Hide UI; clicking empty space or pressing Escape brings them back.
- Added server-owned mob Flying Sparks and Spark Debris colors alongside the tracer Start/Middle/End colors. All default to white, and mob impacts keep using the tracer palette.

Use matching client and server versions. Older presets remain supported. Keeping settings preserves saved values; Reset applies the new defaults.
